# Loderite

A creative-mode voxel game where the blocks are not cubes.

Loderite is built on **truncated octahedra** -- the space-filling cell of the body-centred cubic
lattice. Every block has 14 faces: 6 squares and 8 hexagons. Blocks meet face-to-face in a
lattice that has no 90-degree grid, so builds lean, interlock and curve in ways a cube world
cannot reach. It runs in the browser, installs as a PWA, and works offline.

![A Loderite landscape built from truncated octahedra: rolling green terrain and trees whose
hexagonal faces catch the light, a stone-and-glass shelter at the centre, and the demo arena's
boundary pillars rising into a pale sky.](demo-wide.png)

**Play:** https://loderite.app

## This repository is for issues only

There is no source code here, and that is deliberate. Loderite is closed-source for now. This
repo exists so that **bug reports, feedback and ideas have a public home** -- one you can read,
search and link to without an account, and without going through a form that swallows your words.

- **Found a bug, or want something?** [Open an issue](https://github.com/loderite/loderite/issues/new).
- **Reporting from inside the game?** Use the in-game feedback button -- it prefills the title
  and body for you, including which version you were on. That version line is usually the
  difference between a bug we can find and one we cannot.

Filing needs a free GitHub account. If you would rather not make one, the game's feedback button
also offers an email route -- nothing is lost by taking it.

## What is useful in a report

No template, no required fields. But these help more than anything else:

- **What you did, what happened, what you expected.** In that order, in your own words.
- **The version**, from the badge in the corner of the screen. The in-game button fills this in.
- **Your device and browser**, especially on phones and tablets.
- **A screenshot**, if it is a visual thing. You can paste one straight into an issue.

A vague report is still worth filing. "The moons look wrong somehow" is a real signal, and it has
already found real bugs.

## What to expect

This is a small project, so replies are not instant. Issues are read. Duplicates are fine -- if
two people hit the same thing, that is information, not noise.

## Not here

- **Source code.** Closed for now; that may change.
- **Security reports.** Please do not file those publicly. Use the email route in the game's
  feedback panel instead.
